# Ritratto di Dario Chiapperini

Fonte: https://www.dariochiapperini.dev/office_day.png, immagine pubblicata sul sito personale e indicata dall'autore per l'uso nella pagina FastAng.

- `dario-original.png`: file scaricato dal sito, invariato.
- `dario-640.webp`: export per il web, proporzioni mantenute, senza ritocchi al volto o al contenuto.
- Rigenerazione: `npm run author:assets` (Sharp, ridimensionamento e codifica).

La presenza di questo asset nel progetto non implica una licenza generale di riutilizzo della fotografia.
